The **@f5-sales-demo/i18n-core** TypeScript package provides the single source of truth for locale registry definitions, BCP-47 / ISO-639 conversions, path normalization, and Astro Starlight internationalization configuration across the fleet.

## Core Modules

<CardGrid>
  <Card title="Canonical Registry" icon="document">
    Registry of 13 supported languages including localized display names, writing directions (LTR/RTL), and BCP-47 codes.
  </Card>
  <Card title="Slug & Path Resolution" icon="puzzle">
    Bi-directional slug transformation between root English paths and localized routes.
  </Card>
  <Card title="Starlight Adapter" icon="star">
    Pre-configured Starlight <code>locales</code> configuration builder for <code>astro.config.mjs</code>.
  </Card>
</CardGrid>
